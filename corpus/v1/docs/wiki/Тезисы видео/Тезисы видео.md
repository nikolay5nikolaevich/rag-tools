# Тезисы видео

Рабочая папка для компактных выжимок по каждому разобранному ролику.

Один файл = один ролик. Здесь хранится не полный транскрипт и не вся доказательная заметка, а тезисы с короткой аргументацией, практические действия и готовые формулировки для будущего общего документа.

## Правило слоя

- Полный сырой текст живёт в `raw/`.
- Доказательная заметка живёт в `wiki/Источники видео/`.
- Рабочая выжимка по ролику живёт здесь, в `wiki/Тезисы видео/`.
