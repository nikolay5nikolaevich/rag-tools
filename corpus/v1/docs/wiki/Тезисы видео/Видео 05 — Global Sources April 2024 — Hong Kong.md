# Видео 05 — Global Sources April 2024 (Hong Kong)

## 1. Короткий фокус материала
Влог-обход выставки Global Sources (April 2024, Гонконг, 9000+ стендов) глазами сорсинг-агента: регистрация, навигация по категориям, переговоры с поставщиками про MOQ, FOB-цены, кастомизацию и сертификаты. Самый профильный источник корпуса. Ракурс — со стороны байера/закупщика, но даёт прямое «зеркало» для экспонента: что байеры спрашивают и проверяют на стенде. Полезен для блоков выбор, подготовка, работа на мероприятии и кейсы/ошибки.

## 2. Главная польза для исследования
Реальная механика B2B-выставки: единый скрипт квалификации поставщика (MOQ → цена → кастом → серты → сток), тактика пробного стокового заказа для снижения риска, правило проверки сертификатов по факту, стратегия фабрики Китай/Вьетнам. Для экспонента это чек-лист того, что нужно подготовить к стенду.

## 3. Ключевая фактура
- Факт: регистрация — QR-самрег на входе или онлайн заранее; 9000+ стендов.
  Что это значит для компании: низкий барьер входа для посетителя; обойти всё нельзя — нужен план по категориям.
- Факт: у всех поставщиков повторяется один набор вопросов — MOQ, FOB-цена, скидка с объёма, кастом (логотип/цвет/упаковка), tooling-кост, локация фабрики, сертификаты, сток.
  Что это значит для компании: экспонент должен иметь готовые ответы на каждый пункт прямо на стенде.
- Факт: пробный заказ из стока (муги — от 50–200 шт.) перед масштабированием с кастомом.
  Что это значит для компании: наличие стока под пробную партию снижает барьер первого контакта — конкурентное преимущество.
- Факт: «логотипы сертификатов можно распечатать — нужно видеть сами сертификаты»; состав сертов зависит от категории/рынка (BSCI/FDA/ISO/CE; SGS/CPNP/CPSR; ISO 13485/MDSAP/510K/MDL/TGA).
  Что это значит для компании: готовить реальные сертификаты под целевой рынок к показу по запросу.
- Факт: фабрики чехлов в КНР (быстрее) и Вьетнаме (обход тарифов); встреча с поставщиком, знакомым по CES в январе.
  Что это значит для компании: локация фабрики — осознанный выбор; связи строятся через серию выставок года.

## 4. Основные тезисы
1. **Единый скрипт квалификации поставщика на стенде.** Аргументация: один и тот же набор вопросов у всех поставщиков — устойчивая механика, а не разовый приём.
2. **Пробный стоковый заказ снижает риск первого контакта.** Аргументация: проверка цены/качества/сроков/таможни/возвратов малой партией перед масштабированием.
3. **Сертификаты проверять по факту, не по баннеру.** Аргументация: логотипы легко распечатать; состав сертов зависит от категории и рынка.
4. **Кастом + free tooling + низкий MOQ — оффер-преимущества фабрики.** Аргументация: чехлы — free tooling и кастом от 100 шт.; муги — кастом от 500 шт.
5. **Локация фабрики — стратегический выбор.** Аргументация: Китай (скорость) vs Вьетнам (тарифы/политика).
6. **Логистическая экономика зашита в продукт.** Аргументация: маленькое/лёгкое = низкие доставка/хранение — аргумент продажи и фактор маржи.
7. **Выставочный год — цепочка событий.** Аргументация: CES (январь) → Global Sources (апрель), отношения с поставщиками копятся. Подтверждает длинный горизонт из видео 01.

## 5. Практические действия для компании
### До выставки (экспоненту)
- Подготовить готовые ответы: MOQ, FOB-цена, сетка скидок, стоимость/сроки кастома, tooling-кост, локация фабрики, сроки доставки.
- Привезти реальные сертификаты под целевой рынок и категорию; подготовить сток под пробные заказы.
- (Байеру) зарегистрироваться онлайн, составить план обхода по категориям.

### Во время выставки
- (Экспоненту) отвечать по скрипту, который ждут байеры; предлагать пробную партию из стока, OEM/ODM, free tooling.
- (Байеру) применять единый скрипт квалификации, требовать сертификаты по факту, фиксировать контакты поставщиков.

### После выставки
- Фиксация контактов (WhatsApp/email) под follow-up; пробный заказ как первый шаг к масштабированию.

## 6. Что можно вставить в итоговый документ
- «На сорсинг-выставке у профи-байеров единый скрипт квалификации поставщика: MOQ → FOB-цена → скидка с объёма → кастом (логотип/цвет/упаковка) → tooling-кост → локация фабрики → сертификаты → сток. Экспонент должен иметь готовый ответ на каждый пункт».
- «Сертификаты проверяются по факту, а не по логотипам на баннере; состав зависит от категории и целевого рынка».
- «Сток под пробный заказ снижает барьер первого контакта с новым покупателем и часто решает первую сделку».
- «Отношения с контрагентами строятся через серию выставок года (CES → Global Sources), а не одно событие».

## 7. Ограничения источника
- Жанр — промо-влог сорсинг-агента (есть рекламная вставка/квиз); тон продающий, отбор поставщиков неслучаен.
- Ракурс байерский: выводы для экспонента получены «зеркалированием», прямой методики участия-как-экспонента в источнике нет.
- Цены/MOQ — точечные котировки конкретных поставщиков, не рыночные бенчмарки.
- Нет данных по follow-up, переговорной воронке после шоу, ROI участия экспонента.
- ASR-искажения терминов (BSEI→BSCI, FGB, TTA→TGA, «Spiritly», «BTOC»→B2C).
