# T-31 — Фронт на живом API и экран «Проверка качества»

**Зависит от:** T-22, T-30. Продолжение T-14.

Переключить фронт с моков на живой API, наполнить третий экран данными из
`GET /api/eval/summary`: проверочный набор, таблица сравнения четырёх подходов, разобранные
примеры ошибок — включая неудачные. Демо должно проходить пять сценариев из спеки (раздел 4),
включая обязательный отказ и вопрос про окупаемость.
