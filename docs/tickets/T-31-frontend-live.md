# T-31 — Фронт на живом API и экран «Проверка качества»

**Зависит от:** T-22, T-30. Продолжение T-14.

Переключить фронт с моков на живой API, наполнить третий экран данными из
`GET /api/eval/summary`: проверочный набор, таблица сравнения четырёх подходов, разобранные
примеры ошибок — включая неудачные. Демо должно проходить пять сценариев из спеки (раздел 4),
включая обязательный отказ и вопрос про окупаемость.

---

## Результат: что должно лежать на диске, когда тикет закрыт

| Артефакт | Что в нём |
|---|---|
| `frontend/src/api/client.ts` | переключён с моков на живой API |
| `frontend/src/screens/Quality.tsx` | наполнен данными из `/api/eval/summary` |
| `frontend/tests/demo.spec.ts` | сценарии демо |

---

## Приёмка: чем проверяется, что готово

| Проверка | Ожидание |
|---|---|
| Пять сценариев спеки (раздел 4) | проходят на живом API, включая обязательный отказ и вопрос про окупаемость |
| Экран «Проверка качества» | показывает проверочный набор, таблицу четырёх подходов и разобранные ошибки |
| Неудачные примеры | показаны наравне с удачными, не спрятаны |

Строки таблицы — условия закрытия тикета. Разошлось с реальностью — эскалация
тех-лиду с конкретными файлами, а не правка ожидаемого под факт.
