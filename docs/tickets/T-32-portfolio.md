Закрыть все пункты раздела 9 спеки: демо на публичном профиле, запуск без обязательных внешних
ключей для индексации, проверочный набор с ручной разметкой, таблица четырёх подходов со
временем и стоимостью, измеренное согласие судьи, разобранные ошибки, формулировка
коммерческого контекста из раздела 0 спеки — дословно, без усиления.

Отдельным абзацем: обратная связь при малом n — качественный сигнал, выносится как разобранные
случаи, а не как проценты.
