# T-32 — README, отчёт, разобранные ошибки

**Зависит от:** T-30. Тех-лид пишет текст, исполнитель — воспроизводимый запуск.

Закрыть все пункты раздела 9 спеки: демо на публичном профиле, запуск без обязательных внешних
ключей для индексации, проверочный набор с ручной разметкой, таблица четырёх подходов со
временем и стоимостью, измеренное согласие судьи, разобранные ошибки, формулировка
коммерческого контекста из раздела 0 спеки — дословно, без усиления.

Отдельным абзацем: обратная связь при малом n — качественный сигнал, выносится как разобранные
случаи, а не как проценты.

## Приёмка: чем проверяется, что готово

| Проверка | Ожидание |
|---|---|
| Все пункты раздела 9 спеки | закрыты по списку, поимённо |
| Запуск рецензентом | воспроизводится по README на чистой машине без платного ключа |
| Формулировка коммерческого контекста | дословно из раздела 0 спеки, без усиления |
| Обратная связь при малом n | вынесена как разобранные случаи, а не как проценты |

Строки таблицы — условия закрытия тикета. Разошлось с реальностью — эскалация
тех-лиду с конкретными файлами, а не правка ожидаемого под факт.
