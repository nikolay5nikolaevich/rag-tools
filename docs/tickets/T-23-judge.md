# T-23 — LLM-судья и измерение его согласия с ручной разметкой

**Пакет:** `backend/ergovault/eval/judge.py`. **Зависит от:** T-13, T-03, T-04, T-15.

Судья оценивает: подтверждает ли фрагмент утверждение. Модель и промпт судьи — **другие**, чем у
генератора (`claude-sonnet-5`), иначе он оценивает сам себя.

Порядок обязателен: сначала тех-лид размечает руками 40–50 пар «утверждение ↔ фрагмент»
(`eval/judge_calibration.yml`), затем судья прогоняется по ним, затем считается согласие
(доля совпадений + Cohen's kappa) и **публикуется рядом с любой цифрой подтверждённости**.
Цифра «подтверждённость 87%» без измеренного согласия судьи в отчёт не идёт.

**Про temperature.** В режиме подписки (`EV_LLM_BACKEND=cli`) задать temperature нельзя —
headless Claude Code её не принимает. Поэтому детерминизм не постулируется, а измеряется:
прогнать судью по калибровочному набору **трижды**, посчитать долю расхождений между
прогонами и опубликовать её рядом с согласием. Формулировка «temperature=0» в отчёте
запрещена, если реально работал бэкенд `cli`.

Тесты: расчёт kappa на синтетике с известным ответом; отчёт содержит согласие, число
размеченных пар и разброс между повторными прогонами.
