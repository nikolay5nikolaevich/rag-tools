# T-33 — Пилотный профиль: raw/ как primary (опционально)

**Зависит от:** T-10, T-20.

`EV_PROFILE=pilot` добавляет в индекс `raw/` как тип `primary` с `visibility='pilot'`.
Аналитический и первичный слои остаются раздельными по типу: заметка ведёт к первичному
материалу, но не превращается в самостоятельное доказательство.

Главный тест тикета — негативный: при `EV_PROFILE=public` ни один эндпоинт, ни один ответ и ни
один экран не отдают ни единого символа из `raw/`. Утечка = стоп-релиз.
Корпус пилота не выкладывается и не коммитится.

## Приёмка: чем проверяется, что готово

| Проверка | Ожидание |
|---|---|
| `EV_PROFILE=pilot` | добавляет `raw/` как тип `primary` с `visibility='pilot'` |
| `EV_PROFILE=public` | ни один эндпоинт, ответ или экран не отдаёт ни символа из `raw/`. Утечка = стоп-релиз |
| Разделение слоёв | `primary` и аналитический слой раздельны по типу; заметка ведёт к первичному материалу, но не заменяет его |
| Корпус пилота | не выложен и не закоммичен |

Строки таблицы — условия закрытия тикета. Разошлось с реальностью — эскалация
тех-лиду с конкретными файлами, а не правка ожидаемого под факт.
