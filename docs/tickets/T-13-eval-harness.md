# T-13 — Eval-харнесс: раннер, retrieval-метрики, отчёты

**Пакет:** `backend/ergovault/eval/` (кроме судьи — он в T-23).
**Читать перед стартом:** `docs/CONTRACTS.md` §6, §10; `eval/golden/README.md` (формат разметки).
**Зависит от:** T-00, T-03 (golden set).

## Задача

Инфраструктура измерений: прогнать набор вопросов через любой ретривер/пайплайн, посчитать
метрики, сохранить прогон так, чтобы его можно было сравнить с другим через месяц.

## Что сделать

1. `ergovault/eval/dataset.py` — загрузка `eval/golden/*.yml` в модель `GoldenQuestion`
   (поля: `id`, `question`, `category` A–F, `expected_source_ids`, `must_contain`,
   `must_not_contain`, `answerable: bool`, `notes`, `holdout: bool`).
   **Holdout не читается** без явного `--include-holdout`; по умолчанию его вообще нет в выборке.
2. `ergovault/eval/runner.py` — прогон: вопрос → ретривер → (опционально) генератор → запись
   `eval/runs/<timestamp>-<label>.jsonl`. Каждая строка несёт четыре версии из §10 контракта.
3. `ergovault/eval/metrics.py` — retrieval-метрики: `recall@k` по `expected_source_ids`
   (совпадение на уровне **источника**, не чанка), `MRR`, доля вопросов с пустой выдачей.
   Отдельно — метрики отказа: precision/recall корректного отказа по `answerable`.
4. `ev eval retrieval --mode fts|vector|hybrid [--k 5]` → таблица в stdout + Markdown-отчёт
   `eval/reports/`.
5. **Обязательно:** в каждом отчёте печатать доверительный интервал или прямую оговорку, что при
   n≈35 разница меньше ~15 п.п. неотличима от шума. Это требование спеки, а не украшение —
   отчёт без оговорки не принимается.
6. Тесты: метрики на синтетическом наборе с известным ответом; holdout не попадает в выборку
   без флага (тест обязателен — это защита от самообмана).

## Границы

- LLM-судью не реализовывать (T-23). Здесь только детерминированные метрики.
- Не менять golden set. Нашёл ошибку в разметке — в отчёт тикета, правит тех-лид.
- Не подгонять метрику под красивую цифру: сначала честный расчёт, потом обсуждение.

## Готово, когда

`ev eval retrieval --mode fts` даёт воспроизводимый отчёт на golden set, holdout-тест зелёный.
